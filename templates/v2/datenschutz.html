2. Grundsatz: Daten bleiben auf Ihrem Gerät

Die Anwendung speichert Ihre Anlässe, Proben und Beurteilungen ausschliesslich im Speicher Ihres Browsers (localStorage) auf dem verwendeten Gerät. Diese Daten werden nicht an uns übertragen. Sie können sie jederzeit unter «Daten & Datenschutz» löschen oder als Datei sichern.

Beim Aufruf der Seite lädt die App lediglich ihre Programmdateien sowie die Nährwerttabelle (Agroscope) vom Server. Dabei fallen technisch bedingt Zugriffsdaten an (IP-Adresse, Zeitpunkt, aufgerufene Datei, Browserkennung), die der Webserver bzw. Reverse-Proxy für den sicheren Betrieb kurzzeitig protokollieren kann. [Aufbewahrungsdauer der Server-Logs ergänzen]

Es werden keine Cookies, keine Analyse- oder Tracking-Werkzeuge und keine Inhalte von Drittanbietern (z. B. Schriftarten, CDNs) eingesetzt.

3. PDF-Berichte und QR-Codes

PDF-Berichte werden direkt in Ihrem Browser erzeugt. Sie enthalten neben der Darstellung die Eingaben in kodierter Form, damit die Beurteilung später wieder importiert werden kann. Der QR-Code enthält die Eingaben im Teil der Adresse nach dem «#»; dieser Teil wird vom Browser nicht an den Server übermittelt. Beachten Sie: Wer den PDF-Bericht oder QR-Code erhält, kann die enthaltenen Angaben lesen.

4. Speicherung auf dem Server (nur mit Einwilligung)

Nur wenn Sie für einen Anlass ausdrücklich «Auf Server speichern» wählen und zustimmen, wird er auf dem Server von apps.graswachstum.ch gespeichert. [Serverstandort / Hoster ergänzen]

  • Ende-zu-Ende-Verschlüsselung personenbezogener Angaben: Titel und Ort des Anlasses, Probenbezeichnungen, Herkunft/Betrieb, Namen der Beurteilenden und Notizen werden in Ihrem Browser mit AES-256-GCM verschlüsselt. Der Schlüssel ist nur im Freigabe-Link (Teil nach «#») enthalten, der vom Browser nicht an den Server übermittelt wird. Weder der Betreiber noch Dritte mit Zugriff auf den Server oder dessen Sicherungen können diese Angaben lesen.
  • Lesbar gespeichert werden die Beurteilungsdaten ohne Personenbezug (Futterart, Bestand, Stadium, Antworten der Beurteilungsräder, Messwerte, Schnittdatum). Sie können für anonyme, zusammenfassende Auswertungen verwendet werden. Der Server weist Daten zurück, die in diesen Feldern Freitext enthalten.
  • Zugriff: Es gibt einen Bearbeiten- und einen Nur-Ansehen-Link. Wer einen Link besitzt, sieht alle Angaben des Anlasses. Der Server speichert nur Prüfwerte (Hashes) der Zugriffsschlüssel. Links können jederzeit erneuert werden; alte Links sind danach ungültig.
  • Zweck und Rechtsgrundlage: Zugriff von mehreren Geräten und gemeinsames Erfassen; Ihre Einwilligung (Version und Zeitpunkt werden gespeichert).
  • Löschung: Automatisch {{ (retention_days / 30.4)|round|int }} Monate nach der letzten Änderung, jederzeit selbst über «Vom Server löschen».
  • Schutz vor Missbrauch: Anfragen werden pro Absender begrenzt; dafür wird ein gekürzter Hashwert der IP-Adresse kurzzeitig im Arbeitsspeicher gehalten, nicht gespeichert.

Erfassen Sie Angaben zu anderen Personen (z. B. Betriebsname) nur, wenn diese damit einverstanden sind.

4a. Kursmodus (Schulklassen, Gruppen)

  • Teilnahme: Es genügt ein frei gewählter Anzeigename. Die Teilnahme ist dann an das verwendete Gerät gebunden (Sitzungsschlüssel im Browser). Freiwillig kann eine E-Mail-Adresse bestätigt werden, um sich auf anderen Geräten anzumelden.
  • E-Mail-Adressen (Kursleitung immer, Teilnehmende freiwillig) werden mit einem Serverschlüssel verschlüsselt gespeichert und nur für den Versand von Einmal-Codes verwendet. Die Kursleitung sieht die Adressen der Teilnehmenden vollständig, andere nur gekürzt.
  • Ende-zu-Ende verschlüsselt (Schlüssel im Kurs-Link bzw. auf dem QR-Etikett): Kurstitel, Anzeigenamen, Probenbezeichnungen, Standortangaben (PLZ, Ort, Höhe, auf ca. 1 km gerundete Position), Notizen und Fotos. Wer ein Etikett oder den Kurs-Link besitzt, kann dem Kurs beitreten.
  • Laborwerte einer Probe gibt der Server erst frei, wenn die Kursleitung dies als Hilfestellung erlaubt oder die betreffende Person ihre eigene Beurteilung abgegeben hat.
  • Beurteilungen: Abgegebene Beurteilungen sind für Kursmitglieder sichtbar, für Teilnehmende erst nach der eigenen Abgabe. Die Beurteilungsdaten ohne Personenbezug sind auf dem Server lesbar.
  • Fotos: höchstens 20 MB je Person und Kurs; Neu-Codierung im Browser entfernt Standort- und Kameradaten.
  • Löschung: Teilnehmende können jederzeit austreten (Name, Fotos und Abgaben werden gelöscht). Die Kursleitung kann Personen entfernen oder den Kurs löschen. Automatische Löschung {{ (retention_days / 30.4)|round|int }} Monate nach der letzten Änderung.

4b. Probenpool für Kursleitende

Kursleitende können ausgewählte Proben bewusst für andere freigeschaltete Kursleitende veröffentlichen (Bezeichnung, Beschreibung, Region ohne PLZ und Position, Laborwerte, Fotos, ausgewählte Beurteilungen als anonyme «Referenz»). Diese Einträge sind für alle Kursleitenden lesbar und daher nicht Ende-zu-Ende verschlüsselt, sondern mit Serverschlüssel gespeichert. Sie enthalten keine Personennamen; die veröffentlichende Person bestätigt dies. Einträge können von ihr oder vom Betreiber gelöscht werden.

4c. Antrag Kursleitung

Wer Kurse anlegen möchte, kann einen Antrag stellen (Name, Organisation, kurze Begründung, bestätigte E-Mail-Adresse). Diese Angaben werden verschlüsselt gespeichert und nur vom Betreiber zur Prüfung gelesen.

4d. Speichern eigener Anlässe auf dem Server

Erfordert eine bestätigte E-Mail-Adresse (Schutz vor Missbrauch des Speicherplatzes). Sie wird verschlüsselt gespeichert und nicht weitergegeben. Fotos: höchstens 20 MB je Anlass.

4e. Laborbericht lesen (Texterkennung)

  • Auf dem Server (nur nach Zustimmung): Das gewählte PDF bzw. Foto wird verschlüsselt (HTTPS) übertragen, ausschliesslich im Arbeitsspeicher bzw. einem temporären Verzeichnis verarbeitet und unmittelbar danach gelöscht. Es wird nichts gespeichert und der Inhalt nicht protokolliert. Zurückgegeben werden nur die erkannten Laborwerte.
  • Auf dem Gerät: Die Erkennung läuft vollständig im Browser; die Datei verlässt das Gerät nicht.
  • Bitte decken Sie Adresse und Namen vor dem Fotografieren ab oder schwärzen Sie sie in der App.
  • Übernommene Laborwerte werden wie die übrigen Angaben behandelt (lokal; bei Freigaben Ende-zu-Ende verschlüsselt).
